## Overview

This repository contains the public static build and media assets for the KOYAMA PLUS website.

The web experience is structured around two commercial activities:

- Product catalogue and online product discovery
- Professional cleaning-service presentation

The project is kept public as a client-facing web delivery example.

---

## Repository notes

The current repository contains **compiled deployment assets** rather than the original development workspace. Hashed JavaScript/CSS bundles and the production `index.html` are included alongside media files used by the website.

```text
koyamaplus-sarlu2026/
├── index.html
├── index-*.js
├── index-*.css
├── product & service media assets
├── brand assets
└── README.md
```
