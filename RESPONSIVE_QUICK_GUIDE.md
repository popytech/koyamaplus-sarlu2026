## 📞 QUICK REFERENCE

**Mobile Layout Issues?**
→ Check `src/responsive-mobile.css` for media queries

**Component Not Responsive?**
→ Use Tailwind classes: `sm:`, `md:`, `lg:`, `xl:`, `2xl:`

**Grid Problems?**
→ Review grid classes in component: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4`

**Font Too Small?**
→ Check `src/index.css` font-size media queries
